# Nix入門

Nixは関数型パッケージマネージャーです. Nixは宣言的、すなわちパッケージやその設定について値のように扱います.
さらに副作用のないため, パッケージは再現が可能です.

# Nix言語
Nixは関数型プログラミング言語でパッケージについて記述する. その記述する言語をNix言語と呼び, Nix言語は遅延評価が可能な純粋関数型でドメイン固有言語(DSL)です。

関数型

## 関数型
nix言語は動的型付けの関数型言語です.

```nix
# practice01.nix
let
    x = 1;
in
    x
```

```sh
nix eval --file practice01.nix 
```
