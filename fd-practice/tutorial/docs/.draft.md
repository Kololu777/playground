# Architecture Draft (WIP)

## Overview

This document outlines the proposed architecture for the next major version.

## Components

- **API Gateway**: Routes requests to appropriate services
- **Auth Service**: Handles authentication and authorization
- **User Service**: Manages user data and profiles
- **Notification Service**: Email and push notifications

## Database Schema

- Users table with roles and permissions
- Sessions table for token management
- Audit log for tracking changes

## Open Questions

- Should we use GraphQL or REST for the public API?
- How to handle rate limiting across services?
